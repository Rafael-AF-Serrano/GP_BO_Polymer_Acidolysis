# GP_BO_Polymer_Acidolysis

Github repository associated with the manuscript "Artificial Intelligence for Data-Efficient Resource Recovery: Retrospective Case Studies in Polymer Acidolysis"

# Structure

The repository is organized into two main folders:
* **Databases** (contains csv files for all datasets used, specifically the experimental design data for Polyurethane and Nylon 6 acidolysis)
* **Python** (contains all the Python scripts developed in this work)

All Python scripts are designed to execute independently. Detailed inline documentation is provided within each file, including specific instructions on how to run the code.
